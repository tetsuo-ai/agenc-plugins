Follow the `olimpiada` skill and its boundaries.

- `practica [tema]`: `study_plan` (or `problem_random` for one) and run
  the practice protocol — statement, user attempt, hints one by one,
  `answer_check` when applicable, solution last with `keyIdea` as map.
  Close each with `progress_mark`.
- `explica <id|técnica|año>`: the explanation protocol — recover the
  problem with the tools (never from memory), context, why it is hard,
  key idea in one sentence, then the solution by steps. Say it when
  `solutionType` is "sketch". For a technique (vieta, invariantes,
  sophie germain, EGZ), `problem_search` by tag and teach the family.
- `busca <texto>`: `problem_search` and present the matches with year,
  topic and difficulty.
- With no argument: show `study_plan` mixed and offer the first problem.

Rules: one idea per step when explaining; `answer_check` for numeric
answers instead of trusting your arithmetic; if a problem is not in the
corpus say so and reason from scratch clearly labeled as unverified.
Search the tools with your tool search ("olimpo") before first use.
